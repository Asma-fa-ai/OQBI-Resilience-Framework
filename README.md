# OQBI Resilience Framework

Conference presentation **Building an Integrated Resilience Framework**, built as self-contained, animated HTML decks for a 1280 × 768 LED screen (5 m × 3 m).

Each deck is a single HTML file. Logos, photos and the typeface are embedded, so it runs offline.

## Versions

| Folder | Deck | Look |
|---|---|---|
| `version-1/` | OQBI Resilience Framework - Conference Deck.html | 14 slides, including a stand-alone "How were we able to do that?" slide. Dark Sea-green stage with a slow 3D network background and OQBi brand colours throughout. |
| `version-2/` | OQBI Resilience Framework - Conference Deck V2.html | 17 slides. Black stage with a pool of light, numbered chapter cards, takeaway headlines, mostly white and grey with OQBi orange as the accent, and one idea per click. |
| `version-3/` | OQBI Resilience Framework - Conference Deck V3.html | 14 slides in Monsoon, Sand and Aqua. Version 1 with a clean, still background (no particle effects), the steady line through the storm on slide 2, and a chapter light tube along the bottom. |

## Presenting

Open the file in Chrome, then:

| Key | Action |
|---|---|
| → / Space / Page Down / click | Next build or slide (works with a presentation clicker) |
| ← / Page Up | Back |
| F | Full screen |
| B | Black screen |
| E | Edit slide titles (saved in the browser on that computer) |

The deck scales to any window and fills a 1280 × 768 screen exactly in full screen.
